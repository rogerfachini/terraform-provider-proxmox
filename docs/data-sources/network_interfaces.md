# Data Source: proxmox_network_interfaces

Retrieves the network interfaces of a Proxmox VE node, as found in its network configuration. This is useful for discovering physical interfaces, or for checking that an interface exists before referencing it from a bridge, bond, VLAN or SDN fabric.

## Example Usage

```terraform
# List all network interfaces of a node
data "proxmox_network_interfaces" "all" {
  node_name = "pve"
}

# List the physical interfaces whose name starts with "nic" and that have link
data "proxmox_network_interfaces" "fabric_nics" {
  node_name = "pve"
  type      = "eth"

  filters = {
    name   = "^nic[0-9]+$"
    active = true
  }
}

output "fabric_nic_names" {
  value = data.proxmox_network_interfaces.fabric_nics.interfaces[*].name
}

# List every bridge a guest can attach to, including SDN VNets
data "proxmox_network_interfaces" "bridges" {
  node_name = "pve"
  type      = "any_bridge"
}
```

## Schema

### Required

- `node_name` (String) The name of the node.

### Optional

- `filters` (Attributes) Client-side filters for narrowing down results. An interface must match all filters that are set. (see [below for nested schema](#nestedatt--filters))
- `type` (String) Only list interfaces of this type. The filter is applied by Proxmox VE. Besides the interface types (`eth`, `bridge`, `bond`, `vlan`, `alias`, `fabric`, `vnet`, `OVSBridge`, `OVSBond`, `OVSPort`, `OVSIntPort`), `any_bridge` lists Linux, OVS and SDN bridges, `any_local_bridge` lists Linux and OVS bridges, and `include_sdn` lists all interfaces together with SDN VNets.

### Read-Only

- `interfaces` (Attributes List) The network interfaces, ordered by their position in the node's network configuration. (see [below for nested schema](#nestedatt--interfaces))
