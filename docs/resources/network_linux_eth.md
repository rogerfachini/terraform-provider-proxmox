# Resource: proxmox_network_linux_eth

Manages the configuration of a physical (`eth` type) network interface in a Proxmox VE node.

The interface itself is hardware and is neither created nor removed by this resource. Creating the resource adopts the existing interface and applies the configured settings; destroying it removes only the settings this resource manages (`mtu`, `comment`, addresses and gateways) and leaves the interface in place.

~> PVE resets an interface to `manual` addressing when it is updated without an address. To avoid silently dropping an address, creating this resource fails when the interface already carries an address or gateway that the configuration does not set.

## Example Usage

```terraform
# Jumbo frames on a physical interface that is used as a bridge port.
resource "proxmox_network_linux_eth" "nic0" {
  node_name = "pve"
  name      = "nic0"

  mtu     = 9000
  comment = "fabric uplink"
}

resource "proxmox_network_linux_bridge" "vmbr1" {
  node_name = "pve"
  name      = "vmbr1"

  ports = [proxmox_network_linux_eth.nic0.name]
  mtu   = 9000
}
```

## Schema

### Required

- `name` (String) The name of an existing physical network interface, e.g. `eno1` or `nic0`.
- `node_name` (String) The name of the node.

### Optional

- `address` (String) The interface IPv4/CIDR address.
- `address6` (String) The interface IPv6/CIDR address.
- `autostart` (Boolean) Automatically start interface on boot. When not set, the current setting of the interface is kept. Not reverted when the resource is destroyed.
- `comment` (String) Comment for the interface.
- `gateway` (String) Default gateway address.
- `gateway6` (String) Default IPv6 gateway address.
- `mtu` (Number) The interface MTU.
- `reload` (Boolean) Whether to reload the node network configuration after this interface is created, updated or deleted (defaults to `true`). When `false`, the change is only staged on the node and takes effect on the next reload. Any reload on the node, including one triggered by another resource, applies all staged changes.
- `timeout_reload` (Number) Timeout for network reload operations in seconds (defaults to `100`).

### Read-Only

- `id` (String) A unique identifier with format `<node name>:<iface>`.

## Import

```shell
#!/usr/bin/env sh

```
